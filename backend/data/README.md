# AgriLink – Backend Data Directory

## ⚠️ IMPORTANT DISCLAIMER

### `agmarknet_sample.csv` is SYNTHETIC DEVELOPMENT DATA

This file is **NOT** real government data. It was algorithmically generated
for development and demonstration purposes only.

| Property | Value |
|---|---|
| **Data type** | Synthetic / Simulated |
| **Source** | Generated by `generate_sample.py` using `numpy` and `pandas` |
| **Official source?** | ❌ NO |
| **Sourced from Agmarknet?** | ❌ NO |
| **Sourced from data.gov.in?** | ❌ NO |
| **Random seed** | `42` (fully reproducible) |
| **Generated on** | 2026-10-02 |

> The price values, market names, and commodity records in `agmarknet_sample.csv`
> are **simulated** to resemble real mandi data in structure and rough magnitude
> only. They must not be used for any real agricultural decision-making,
> financial analysis, or policy work.

## Column Reference

| Column | Type | Description | Example |
|---|---|---|---|
| `State` | String | Indian state name | `Karnataka` |
| `District` | String | District within state | `Mysuru` |
| `Market` | String | APMC / Mandi name | `Mysuru APMC` |
| `Commodity` | String | Crop / produce name | `Tomato` |
| `Variety` | String | Crop variety (may be null) | `Hybrid` |
| `Grade` | String | Quality grade (may be null) | `FAQ` |
| `Arrival_Date` | String | Date of price record (DD/MM/YYYY) | `15/03/2024` |
| `Min_Price` | Integer | Minimum price in ₹/quintal | `800` |
| `Max_Price` | Integer | Maximum price in ₹/quintal | `1400` |
| `Modal_Price` | Float | Most common traded price in ₹/quintal (may be null) | `1100` |

**Note:** Intentional missing values (~1.5 %) and duplicate rows (~0.5 %)
are included so the data cleaning step can be demonstrated during review.
